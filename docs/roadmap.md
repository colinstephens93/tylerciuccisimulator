# Roadmap

## Milestone 1 - Playable skeleton (done)

- Phaser 3 + Vite project, GitHub Pages deploy workflow.
- Full "Morning Run" flow: home -> drive to Wawa -> Wawa lot -> Wawa interior -> drive to school -> school entrance -> results.
- Game clock (7:00 start, 8:00 bell), Tardy fail screen with "Retry this scene" and "Start over".
- Wawa: kiosk ordering (order number, prep time, pickup), Ghost cooler, register, exit check for 1,000 cal / 300 mg goals.
- Driving: steering, brake, traffic, potholes, collisions (+1 min), school zone speed limit, Lights button.
- Amanda calls (3-4 per run, surprise mood, replies, declines, hands-free while driving).
- Scoring and titles, best score saved in the browser.
- Synthesized chiptune music per scene and sound effects; music/SFX toggles.
- Placeholder pixel sprites for Tyler (from the reference photo), patrol car, traffic.

## Milestone 2 - Real Lawrenceville map

- Build script: download OpenStreetMap data for Lawrenceville, convert to a pixel tilemap.
- Route Tyler's walking scenes and drives along real streets; place the fictional Wawa and school.
- OSM credit on the title/credits screen.

## Milestone 3 - Art and polish

- Hand-drawn pixel sprites: Tyler (4-direction walk), patrol car, Wawa interior tiles, school.
- Pixel font, tilted map perspective, nicer transitions.
- Difficulty tuning from playtests (clock speed, traffic density, infraction penalty).

## Later

- Workday scenes at school (hallway patrol, lunch duty, car-rider line).
- More Amanda calls.
