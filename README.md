# Tyler Ciucci Simulator

A small, mobile-friendly browser game about a day in the life of a School Resource Officer (SRO) in Georgia.

**Status:** Requirements phase. No game code yet.

## Documentation

| Doc | Purpose |
| --- | --- |
| [docs/requirements.md](docs/requirements.md) | Game vision, scope, MVP gameplay, and technical requirements |
| [docs/open-questions.md](docs/open-questions.md) | Decisions still needed before (or during) the build |
| [docs/decisions.md](docs/decisions.md) | Log of decisions already made, and why |

## How we work

1. Refine requirements in `docs/` until the MVP is unambiguous.
2. Move answered items from `open-questions.md` into `decisions.md`.
3. Build the MVP in small, playable increments.
